# HousePriceAnalyzer
A complete machine learning project for analyzing and predicting house prices using real estate data.

## Features
- Exploratory Data Analysis (EDA)
- Correlation Heatmap
- Pairplot visualization
- Address encoding
- Feature importance extraction
- Random Forest & Linear Regression models
- Price prediction for new samples

## Project Structure
## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the main script:
   python src/main.py

## Dataset
The dataset is located in `data/housePrice.csv`.

## Model
The trained Random Forest model is saved in:
`models/random_forest_model.pkl`
